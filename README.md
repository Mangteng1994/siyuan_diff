# 文档Diff

思源笔记桌面端插件，提供两个独立功能块：

- **文档对比**：输入两篇文档的 ID / 思源链接，或按标题搜索选择，读取 Markdown 后对比。可使用当前打开文档。
- **复制文段对比**：在左右输入框粘贴文本，或点击「读取剪贴板」。

支持双栏、合并、逐行视图，新增 / 删除字符统计，上一处 / 下一处差异，交换左右，清空和复制差异。

## 安装

1. 从 [最新 Release](https://github.com/Mangteng1994/siyuan_diff/releases/latest) 下载 `package.zip`。本地构建也会生成 `dist/package.zip` 和 `dist/siyuan_diff-0.1.1.zip`。
2. 关闭思源，将安装包中的文件解压到 **思源工作空间** 的 `data/plugins/siyuan_diff/`。确认该目录下直接包含 `plugin.json` 和 `index.js`，不要多嵌套一层目录。
3. 启动思源，在「设置 → 集市 → 已下载 → 插件」中启用「文档Diff」。
4. 点击顶栏对比图标，或通过命令面板执行「打开文档Diff」。默认快捷键为 `Alt + Shift + D`（macOS 为 `Option + Shift + D`）。

桌面端已由用户实测验收。首次集市上架申请提交后，需等待官方审核合并；审核完成前可从 [GitHub Releases](https://github.com/Mangteng1994/siyuan_diff/releases) 下载 `package.zip` 手动安装。当前面向桌面、桌面独立窗口和桌面浏览器，最低声明版本为思源 3.0.12；该最低版本尚未进行实机兼容验证。

如果此前安装过开发版 `siyuan-document-diff`，请先禁用旧插件，再安装正式包 `siyuan_diff`，避免重复入口。两者均不保存文段，无需迁移数据。

## 使用

### 文档对比

左右分别指定原文和修改后的文档。点击「使用当前文档」会填入最近激活的思源文档 ID；也可直接粘贴文档链接或通过标题搜索。搜索最多展示最近修改的 50 篇匹配文档，点击标题选中。

点击「开始对比」读取两个文档的当前 Markdown。对比的是导出结果，包括 Markdown 标记；图片对比其链接，不分析图片像素。思源导出设置可能影响内容，例如块引用展开、自动编号等。标题仅用于标识来源，不单独参与比较。文档在对比后被修改时，需要重新点击开始对比以刷新。

请使用完整文档的 ID，普通段落块会被拒绝。插件不会读取历史快照或比较两个历史版本；如需比较版本，可先将历史内容复制为另一篇文档，或使用文段对比。

### 复制文段对比

切换到「复制文段对比」，左右粘贴文本。剪贴板读取需要宿主权限；无法读取时可使用 `Ctrl + V` / `⌘ + V` 手动粘贴。两个输入框均允许为空，便于查看全文新增或删除。

在面板中按 `Ctrl + Enter` / `⌘ + Enter` 开始对比。编辑输入、切换来源、交换或清空会丢弃旧结果，避免将上一次结果误认为当前结果。

### 阅读结果

- 双栏：左侧标记删除，右侧标记新增。
- 合并：在单个文本流中展示删除线和新增下划线。
- 逐行：展示原文 / 修改后的行号，以及 `+` / `−` 标记。
- 上一处 / 下一处：按当前视图的增删片段循环跳转。一处替换可能分为删除和新增两处。
- 复制差异：复制行级结果，新增行以 `+` 开头，删除行以 `-` 开头；这是阅读用文本，不是可直接应用的补丁文件。

字符统计按 Unicode 码点计数，换行也计入；组合 emoji 可能包含多个码点。CRLF 统一为 LF，其余空格、制表符、大小写与空白行均保留并参与比较。

## 隐私和限制

插件只调用思源当前服务的查询与 Markdown 导出接口，不修改文档、不上传给外部服务，也不保存文段和剪贴板内容。关闭页签后内容不会恢复。剪贴板只在点击相关按钮后读取或写入。

每侧最多 50000 个 UTF-16 单元（多数中文字符占一个，部分 emoji 占两个）。字符级 Myers 路径搜索上限为 1000000 个预算单元；不相同文本的行级 LCS 表最多 4000000 个单元。超限会明确提示分段对比，不以粗略结果冒充精确结果。

## 开发和验证

需要 Node.js 22 或更高版本和 npm。

```sh
npm ci
npm test
npm run typecheck
npm run build
npm run verify:package
```

`npm run check` 执行全部检查。测试采用先失败、再实现、再回归的 TDD 流程，记录见 [docs/tdd.md](docs/tdd.md)。

`npm run preview` 生成独立界面预览 `dist/preview.html`，可在浏览器中直接打开并试用文段对比；文档接口需要在思源内使用。

规则来源：`E:\G_Disk\CodeTest\codex_for_word\codex-for-wps-word\apps\wps-panel\src\diff.ts`。运行时和测试均不依赖参考项目目录。行级沿用 LCS 的回溯平局规则，字符级沿用 Myers 最短编辑路径及合并规则，新增预算限制。

思源接口依据：[官方插件示例](https://github.com/siyuan-note/plugin-sample)、[官方 API 文档](https://github.com/siyuan-note/siyuan/blob/master/docs/API.zh-CN.md)。
