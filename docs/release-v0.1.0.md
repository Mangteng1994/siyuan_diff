文档Diff 首次正式发布，桌面端已由用户实测验收。

- 文档对比：支持文档 ID、思源链接、标题搜索和当前文档。
- 复制文段对比：支持手动粘贴和读取剪贴板。
- 提供双栏、合并、逐行视图，增删统计、差异跳转、交换和复制差异。
- 仅读取文档，不修改笔记，也不向外部服务发送文段。

下载附件 `package.zip`，解压到思源工作空间的 `data/plugins/siyuan_diff/`，在设置中启用「文档Diff」。首次集市上架申请需等待官方审核合并。

如果已经安装开发版 `siyuan-document-diff`，请先禁用旧插件，避免出现重复入口。

支持桌面端、桌面独立窗口和桌面浏览器。Android / iOS 暂不支持；最低声明思源版本为 3.0.12，未对该最低版本单独完成实机验证。

验证：23 项自动测试、TypeScript 严格检查、构建和安装包模拟加载通过；其中黄金摘要覆盖 1922 组参考 diff 规则结果。
