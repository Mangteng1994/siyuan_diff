# TDD 开发与验证记录

开发日期：2026-10-20。用户要求中的 TTD 按测试驱动开发（TDD）执行。

## 已实现范围

- 文档对比：文档 ID、思源链接、标题搜索、当前文档入口，读取完整文档 Markdown。
- 复制文段对比：左右粘贴、剪贴板读取、空文本、交换与清空。
- 双栏、合并、逐行视图，新增删除统计、差异导航、复制差异。
- 沿用参考项目的行级 LCS 和字符级 Myers 规则。
- 中文说明、构建产物、安装 ZIP。

## 红 → 绿 → 重构

1. 先创建 diff 与思源接口测试，在没有实现时运行 `npm test`：两个测试文件因缺少目标模块而失败。
2. 实现对比引擎和文档接口：12 项测试通过。
3. 先创建面板测试，再次运行：界面测试因缺少 `src/panel.ts` 失败，已有 12 项保持通过。
4. 实现面板：18 项测试通过，覆盖两个功能块、视图、导航、安全渲染、剪贴板拒绝、编辑使旧结果失效、销毁后丢弃异步结果。
5. 审核参考规则时增加重复行、重复字符测试，出现真实断言失败。首尾裁剪改变了重复内容的匹配位置；移除行级首尾裁剪和字符级后缀裁剪后，19 项测试通过。
6. 直接对参考模块和当前模块执行 1922 组交叉对比，全部相同。将参考结果 SHA-256 固定在 `tests/reference-golden.json`，增加黄金摘要测试。正常测试不依赖参考项目目录。
7. 保留计算预算和稀疏路径，拒绝过大的计算，避免将平方级字符矩阵带入宿主。

## 自动验证

`npm run check` 包含 Vitest、TypeScript 严格检查、构建和安装包模拟加载。

| 文件 | 验证行为 |
| --- | --- |
| `tests/diff.test.ts` | 行级平局、重复内容、中文和 emoji、空文本、左右还原、换行、统计、资源限制、1922 组规则摘要 |
| `tests/siyuan-client.test.ts` | 链接解析、只读接口调用、段落块拒绝、接口与网络错误、SQL 转义 |
| `tests/panel.test.ts` | 两个功能块、视图、导航、安全渲染、交换清空、剪贴板错误、失效与销毁 |
| `scripts/verify-package.mjs` | ZIP 文件、CommonJS 导出、模拟顶栏打开、当前文档、文段对比、销毁、卸载 |

模拟宿主验证不等于思源实机验证。`npm run preview` 生成独立 HTML 预览 `dist/preview.html`，使用插件面板源码；文档接口仍需要思源宿主。
